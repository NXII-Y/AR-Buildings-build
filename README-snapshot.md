# Сборка Контура и AR за 8 и 9 октября

Подготовленная AR-сборка для новой ветки work/kontur-ar-20261008-09.
Основная ветка и действующая публикация этим снимком не обновляются.

Исходники Контура, метки, запечённые модели и материалы разработки:
https://github.com/NXII-Y/AR-Buildings-web/tree/work/kontur-ar-20261008-09

Для локального показа нужен установленный Node.js 24.
Из этой папки: node scripts/serve-lan.mjs --root .
Общий экран: http://АДРЕС_КОМПЬЮТЕРА:8080/screen/
Телефон: https://АДРЕС_КОМПЬЮТЕРА:8443/AR-Buildings-build/
Для HTTPS сначала создать сертификат на этом компьютере:
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/create-lan-certificate.ps1
Порядок доверия сертификату и настройки сети — docs/local-screen.md исходного проекта.
Локальные закрытые ключи находятся в private и не публикуются в Git.

Подключение телефона к экрану — через Настройки, шестизначный код.
Чёрный осмотр и прежнее вращение сохранены, стрелки переключают Main/MainV2.
Привязка готовится на компьютере; модели и текущая привязка сохранены.
Новые рисунки меток и запечённая модель сохранены как отдельные разработки,
без автоматической подмены активного контента.

Типы, сборка и 84 проверки объединения прошли; физический телефон и экран
переговорной в этой ветке не подтверждены.
